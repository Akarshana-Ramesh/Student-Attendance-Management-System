# Student Attendance Management System

## Introduction

The Student Attendance Management System is a web-based application designed to manage student attendance efficiently. It helps faculty members record, monitor, and generate attendance reports.

## Features

* Student registration
* Mark daily attendance
* View student attendance records
* Generate attendance reports
* Manage class details

## Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub

## Installation

1. Clone or download the project from the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.

## Usage

1. Open the Student Attendance Management System.
2. Select the required class.
3. View the student list.
4. Mark attendance.
5. Generate and review attendance reports.
